# 🎨 Color Changer App

A simple and interactive web application built with HTML, CSS, and JavaScript. This project allows users to change the background color dynamically with a single click and displays the current active color name.

---

## 🚀 Features
- **Change Color Button:** Instantly changes the background color when clicked.
- **Color Indicator:** Displays the name of the current active color on screen.
- **Clean UI:** A minimalist, card-based layout for a smooth user experience.

---

## 🛠️ Technologies Used
- **HTML5:** For structuring the app interface.
- **CSS3:** For styling the card layout and design.
- **JavaScript:** For handling click events and updating the background color dynamically.

---

## 💡 What I Learned
- How to select DOM elements using JavaScript.
- How to attach event listeners (`click`) to buttons.
- How to update element styles and text content dynamically on the fly.
