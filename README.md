# 🎨 Color Changer App

A simple and interactive dynamic styling project built using core web frontend technologies. This project demonstrates real-time DOM manipulation, event handling, and dynamic color changes based on user interaction.

---

## 🚀 Features
- **Dynamic Background Color:** Instantly changes the background color upon button click or input selection.
- **Hex/RGB Color Display:** Displays the active color code on screen.
- **Clean UI:** Minimalist and responsive layout suitable for all screen sizes.

---

## 🛠️ Tech Stack
- **HTML5:** Basic structural markup.
- **CSS3:** Dynamic transitions and layout styling.
- **JavaScript (ES6):** Event listeners, DOM manipulation, and randomized color logic.
